Select a case to inspect its evidence timeline.

WCP analyst runbook and mitigation approval gate
  1. Correlate the request ID across Nginx, baseline detector, ML shadow, and triage timeline.
  2. Review route, cache status, detector mode, indicator codes, and any later client HIT.
  3. Compare with the fixed route and repeat using a clean cache namespace.
  4. Record the evidence and assign the case. Mark false positive only after documenting the control result.
  5. Select a mitigation as pending review. A reviewer name is required to approve or reject it.
  6. Apply any cache-affecting change manually only after review, then verify with a fresh request and independent client.

This API records the review decision only; it has no cache write or enforcement endpoint.
