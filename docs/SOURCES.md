# Nguồn tham khảo kỹ thuật

- [PortSwigger — Web cache poisoning](https://portswigger.net/web-security/web-cache-poisoning)
- [PortSwigger — Cache implementation flaws](https://portswigger.net/web-security/web-cache-poisoning/exploiting-implementation-flaws)
- [NGINX — Proxy module, cache key, bypass và no_cache](https://nginx.org/en/docs/http/ngx_http_proxy_module.html)
- [NGINX — auth_request và auth_request_set](https://nginx.org/en/docs/http/ngx_http_auth_request_module.html)
- [scikit-learn — IsolationForest](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.IsolationForest.html)
- [FastAPI — tài liệu](https://fastapi.tiangolo.com/)

Repo tham khảo đã thảo luận, không được clone hoặc sao chép làm nền project này:

- [nginx-waf-ai](https://github.com/fabriziosalmi/nginx-waf-ai): tham khảo ý tưởng ML cạnh Nginx.
- [PyOD](https://github.com/yzhao062/pyod): lựa chọn mở rộng so sánh mô hình, không là dependency hiện tại.
- [WCVS](https://github.com/Hackmanit/Web-Cache-Vulnerability-Scanner): công cụ bổ trợ kiểm thử, không là detector phòng thủ.

Code project được viết riêng cho bốn ca lab. Dùng API công khai của các thư viện;
không chứa model pretrained tải từ các repo trên. Trích dẫn cả thuật toán/thư
viện lẫn nguồn kỹ thuật khai thác khi viết báo cáo.
